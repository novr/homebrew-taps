# novr/homebrew-taps

novr org 配下の CLI / macOS アプリを homebrew-core 外で配布する tap。各ツール repo の release workflow から Formula / Cask を自動更新する汎用基盤。

```bash
brew tap novr/taps
brew install <formula>
brew install --cask <cask>
```

## Formulae

| Formula | 説明 |
|---------|------|
| `br` | Unofficial Bitrise CLI |
| `rinter` | Rin policy checker |
| `kawarimi-validate` | Kawarimi JSON validator |
